Questions

Before you buy

Is this allowed under Sleeper's rules?
Yes. 4th&Go only reads from Sleeper's public draft API — the same data your browser already loads to show you the draft room. It doesn't automate picks unless you explicitly turn on the optional Draft actions feature using your own session, and even then, it's you clicking the button.
Does it work in mock drafts, or only real leagues?
Both. Sleeper's draft API works identically for mock and real drafts, so 4th&Go syncs to either — mock drafts are actually the easiest way to try it out risk-free before your real draft.
What league format is this built for?
A 10-team, full PPR, 1QB/2RB/2WR/1TE/2FLEX league with no kicker or defense — the board, tiers, and value calculations are all tuned around that shape. It'll still track picks and consensus rankings for other formats, but the BEER/VBD replacement-level numbers assume this league shape specifically.
How do I get my license key after buying?
Your license key is generated and delivered automatically right after checkout — no waiting on us. Paste it into the extension's lock screen once, and it's verified and cached locally, so it keeps working offline for every draft after.
Is it a subscription?
No. It's a single $10 purchase that unlocks the extension for good. No renewal, no per-season fee.
Something's not working — how do I reach you?
Use the feedback button built into the extension's header (a mail icon, no email client needed) — it goes straight to the developer. Bug reports and feature requests both welcome.
